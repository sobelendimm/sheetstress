# Design notes

- Origin: generalized from in-house scanners for a family of Excel templates. Product-specific parts
  (product lists, names, paths, queueing wrappers) were removed; only the generic detection logic remains.
- License: MIT, because all code here was written for this repository and has no copyleft dependency
  (openpyxl is MIT).
- Input classes: valid workbook, corrupt file (exit 2), no unlocked cells, hidden sheets/rows (ignored for
  findings), missing LibreOffice (info, not failure), unknown check name (exit 2).
- Static checks never start LibreOffice; recalculation checks use a throwaway profile directory.
- Samples are synthetic and generated by `examples/make_examples.py`.
